What is a List?
A list stores multiple values in one variable.
Definition: An ordered, mutable collection written using [].    Pasted markdown(2)

Creating Lists
Create a list using square brackets [].
Definition: [] represents an empty list, while values can be placed inside it.

Indexing
Access list items using their position, starting from 0.
Definition: Indexing means accessing an item by its position.

Changing List Values
List values can be changed after creation.
Definition: Lists are mutable, meaning their elements can be modified.

List Length
Use len() to find how many items are in a list.
Definition: len(list) returns the number of items.

Slicing
Slicing gets a portion of a list.
Definition: list[start:end] returns items from start up to, but not including, end.

append()
Adds one item to the end of a list.
Definition: append() adds a single item as the last element.

extend()
Adds multiple items to a list.
Definition: extend() adds elements from another iterable to the list.

insert()
Adds an item at a specific position.
Definition: insert(index, value) places a value at the given index.

remove()
Removes a specific value from the list.
Definition: remove() deletes the first matching value.

pop()
Removes an item using its index, or the last item by default.
Definition: pop() removes and returns an element.

clear()
Removes all items from a list.
Definition: clear() makes the list empty.

index()
Finds the position of a value.
Definition: index() returns the index of the first matching value.

count()
Counts how many times a value appears.
Definition: count() returns the number of occurrences.

sort()
Sorts the original list.
Definition: sort() rearranges list elements in ascending or descending order.

sorted()
Creates a sorted version without changing the original list.
Definition: sorted() returns a new sorted list.

reverse()
Reverses the original list.
Definition: reverse() changes the list order in place.

reversed()
Returns the elements in reverse order.
Definition: reversed() returns a reverse iterator.

copy()
Creates a separate copy of a list.
Definition: copy() creates an independent shallow copy.

= vs copy()
b = a makes both variables refer to the same list.
Definition: b = a.copy() creates a separate list.

Lists + Loops
Loops allow you to process every item in a list.
Definition: A loop repeatedly accesses list elements one by one.

Lists + Conditions
Conditions can filter or check list elements.
Definition: Use if inside a loop to perform actions based on each value.

Nested Lists
A list can contain other lists.
Definition: A nested list is a list whose elements can themselves be lists
